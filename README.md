# 熊猫快递局 · 美术与舒缓节奏版

双击 `index.html` 即可在浏览器中游玩，无须安装依赖。快递局、熊猫、纸箱和藤篮使用生成美术，分类图标由代码统一绘制。

- 所有快递按图案投进对应篮框；每关12件，三种图案各4件，没有放过、盖章或换班规则。第1—10关至少投对9件，后续至少投对10件；按正确入篮比例评分。
- 保持舒缓速度，完整行程预算60秒；投递后0.35秒衔接下一件，因此熟练玩家可提前结束。
- 支持点击快递、空格键、右下角「投递」按钮。关前通过循环动画演示入框点击；文字规则可按需查看。
- 前 3 关先完成 3 次练习。错误练习必须重试，不计入正式成绩。
- 右上角可开关音效；游戏可暂停，切到其他页面自动暂停。
- 浏览器本地保存进度、星级和知识卡；换浏览器或清理浏览数据不会保留进度。

旅程以五章站点呈现，25 个关卡均有城市地标或地方特色插画，卡片之间使用铁路美术连接。铁路为游戏关卡示意，原稿公路剧情保持不变。手机端可以横向滑动站点。知识卡使用原稿文字。

代码：`engine.js` 为规则、节奏和序列；`content.js` 为原文档关卡与知识卡数据；`app.js` 为交互；`visuals.js` 为统一图标和教学动画；`style.css` 与 `art.css` 为样式。`assets/PROMPTS.md` 记录素材提示词和生成方式。
