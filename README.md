# 熊猫快递局

双击“打开熊猫快递局.cmd”启动 localhost 服务；也可以直接用浏览器打开 index.html。

## 当前玩法

- 点击快递投递：图案对应、中心进入篮框即可。没有“放过”、盖章、换班或键盘投递规则。
- 1—20关每关12件，三种标记各4件，同一时间只有一件可操作快递。21—25关上下两线同时出件，每组2件、共12组24件，每条线12件，每种标记在每条线上各4件。
- 单件完整行程：1—18关5秒，19关4.8秒，20关4.6秒；21关恢复为5秒，22关4.8秒，23关4.6秒，24关4.4秒，25关4.2秒。入口观察0.65秒保持不变，双线同时出件关卡的篮框可操作窗口约0.95—1.18秒。同一关内速度固定。
- 独立60秒倒计时，投递时不跳减。单件或一组完成后，以0.35秒落篮动画衔接下一件或下一组；两线同时出件时，点击上方快递不会结束下方快递的行程。所有快递处理完即结算，可提前完成。到时未处理的计漏投。暂停及关前练习不消耗正式时间。
- 1—10关至少投对9/12件，11—20关至少投对10/12件，21—25关至少投对20/24件。前20关全对三星、11件两星，其余达标一星；后5关投对23—24件三星、22件两星、20—21件一星。投错与漏投各损失一件。
- 1—3关篮筐顺序固定，并有三次操作练习；4关起在进入关卡时随机排列。16—17关上下篮筐顺序相同；18关起上下顺序不同，同一列的标记不重复，进入关卡后保持固定，不在快递途中换位置。
- 16关上下交替、每线6件；17—20关双线随机、每线6件，每种标记在线上和线下各2件，最多连续3件出现在同一条线。21关起每组在上下两线各出1件，两件对应不同列，先后点击投递；两件到达目标中心至少相隔0.99秒。每种不同列的上下目标组合各出现两组，生成时按本关实际篮筐位置配对，练习也保证目标错开。单件模式最多连续2件相同标记；同时出件模式每条线各自最多连续2件相同标记。数量均衡且生成有重试上限。
- 进度、星级保存在浏览器本地。旧成绩保留；清除浏览器数据或更换浏览器后不自动同步。

## 关卡递进

五章依次为基础配对 → 细节辨认 → 组合辨认 → 双线入门与提速 → 两线同时操作。16、17关保持原有玩法；18关先增加上下篮筐错位，19、20关分两次提速，21关恢复第18关的速度，并引入同时操作两件快递。22—25关在此基础上逐关提速，并依次增加数量、颜色与填充、方向及数量组合辨认。终关速度高于第20关，但仍慢于最初每件3.9秒的版本。每一步的变化都体现在下一关的图案、布局或操作中。终站完成后进入旅程纪念地图。

## 画面与知识卡

保留25站、五章公路旅程、城市插画和美术素材。知识卡由熊猫讲解，标题与正文分开；城市图片可放大。只为用户指定的“沂、肇”标拼音，关卡标题与知识卡分别保留，卡片内不重复。昆明通关后可展开G42、G2、G4、G80路线示意与五枚章节徽章，首页可重开纪念册。

## 维护与检查

engine.js集中定义图案、车道、篮筐、出件顺序、速度、每关件数与通关门槛；round-update.js依据它更新规则文案。app.js读取同一配置渲染传送带，避免逻辑与画面不一致。content.js中的原始故事、城市和知识正文保留。

使用Node运行 test-engine.cjs、test-browser.cjs、test-concurrent.cjs、test-audio.cjs、test-audio-browser.cjs。浏览器检查需要Playwright和Edge；测试截图属于临时检查文件，查看后删除。

路线图山水使用 `assets/journey-terrain.png` 手绘底图，河流名称、公路、城市标签和交互继续由 SVG 绘制；绘图提示词记录在 `assets/PROMPTS.md`。关卡选择保留编号与星级，移除已抵达卡片右上角的勾选标记。

## 分享测试进度

在首页关卡选择下方点击“导出存档”，把下载的 JSON 文件发给测试者。对方打开同一游戏，在首页点击“导入存档”选择文件，即可使用已解锁关卡、知识图鉴和通关纪念册。25站存档导入后可直接选择全部关卡。

导入会合并记录，逐关保留更高分数和星级，不改变音效设置；无效文件不会修改进度。存档仅包含通关成绩与导出时间，不包含浏览器其他数据。

投递容错：快递中心距篮筐中心不超过传送带宽度的13%即可投递（原10.5%）；相邻篮筐仍不重叠。快递四周额外14像素为透明点击区域，外观与速度不变。

## 清除本地记录

右上角点击“设置”→“清除本地记录”→“确认清除”，会将当前浏览器的通关记录、分数、星级和知识卡收藏清空，回到第1关。点击“取消”或按 Escape 返回设置，不修改记录；关闭设置后继续游戏，设置期间暂停计时。音效偏好及其他游戏的数据保留。可先导出存档备份，清除后仍可导入恢复；已发给别人的存档文件不受影响。

导出、导入存档暂时保留在首页供测试使用，后续正式版移除；设置和清除记录功能独立保留。
